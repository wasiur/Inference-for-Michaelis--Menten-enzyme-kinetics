# Inference for Michaelis--Menten enzyme kinetics

This repository provides the Julia script used to perform parameter inference for the single-stage Michaelis--Menten enzyme kinetic reaction system (Example 4.1) in [1]. The main file is Inference_MM.jl. 

## References
[1] Arnab Ganguly and Wasiur R. KhudaBukhsh. _Statistical inference for a multiscale stochastic model of enzyme kinetics via propagation of chaos_. [arXiv:2409.06565v3](https://doi.org/10.48550/arXiv.2409.06565).
